# 机位图可视化系统

基于KML/KMZ文件的机位图可视化系统，支持地形显示、图例说明和小地图显示风场位置。

## 功能特性

- ✅ 支持KML和KMZ文件上传和解析
- ✅ 地形图层显示（OpenTopoMap）
- ✅ 机位点分类显示：
  - 🟢 现有机位点（绿色）
  - 🔵 未来机位点（蓝色）
  - 🟡 修改的机位点（黄色）
- ✅ 图例说明
- ✅ 右下角小地图显示风场位置
- ✅ 响应式设计

## 安装和运行

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

应用将在 `http://localhost:3000` 启动

### 构建生产版本

```bash
npm run build
```

## 使用方法

1. 点击"上传KML/KMZ文件"按钮
2. 选择你的KML或KMZ文件
3. 系统会自动解析并在地图上显示机位点
4. 点击机位点可以查看详细信息
5. 使用右下角小地图查看风场位置

## KML文件格式说明

系统会自动识别机位点的状态：
- 包含"未来"、"计划"、"新增"等关键词 → 标记为未来机位点
- 包含"修改"、"更新"等关键词 → 标记为修改的机位点
- 其他 → 标记为现有机位点
